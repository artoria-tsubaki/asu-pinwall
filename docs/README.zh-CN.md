# 受 Mistral AI 启发的视觉设计系统

## 1. 视觉主题与氛围

Mistral AI 的界面像用代码渲染出的阳光普照的风景——温暖、大胆、毫不掩饰的欧洲气质；它放弃了常见的「蓝屏 AI」审美，转而采用金琥珀、焦橙色，以及南法午后斜阳的感觉。每一处表面都带着暖意：背景从淡奶油色过渡到深琥珀，阴影带有金色底调（`rgba(127, 99, 21, ...)`），品牌标志性橙色（`#fa520f`）像烽火一样贯穿页面。

设计语言在「温暖」上极尽张扬，在「结构」上却保持极简。巨大的展示标题（82px）以强烈的负字距（-2.05px）撞入视口，文字块像广告牌或抗议海报——是宣言而非描述。字体采用 Arial（很可能为自定义字体，Arial 作为回退），在极大字号下呈现一种不加修饰的粗粝感，仿佛在说「我们做前沿 AI」，无需任何装饰。

Mistral 的辨识度来自对暖色温的彻底坚持。标志性的「色块」身份——从亮黄（`#ffd900`）经琥珀（`#ffa110`）到焦橙（`#fa520f`）的渐变体系——构成一眼可辨的视觉符号。连阴影也是暖的，用带琥珀调的黑色替代冷灰。再配合金色调的宏大风景摄影，整体更像一家恰好在做语言模型的欧洲奢侈品牌，而非典型的科技公司。

**关键特征：**
- 金琥珀色宇宙：从淡奶油（#fffaeb）到焦橙（#fa520f）的完整色阶
- 超大展示字号（82px）与激进负字距（-2.05px）
- 使用带琥珀调的 rgba 构成的暖金色阴影体系
- Mistral「M」色块身份——由黄到橙的渐变
- 暖金色调的戏剧性风景摄影
- 策略性使用大写排版作为区块标签与 CTA
- 接近零的圆角——锐利、建筑感的几何
- 法式/欧式自信：温暖、大胆、宣言式

## 2. 色板与角色

### 主色
- **Mistral Orange**（`#fa520f`）：核心品牌色——鲜明、饱和的橙红，锚定整套身份。用于主强调、品牌色块与最高信号时刻。
- **Mistral Flame**（`#fb6424`）：略偏暖、略亮的品牌橙变体，用于次级品牌时刻与悬停态。
- **Block Orange**（`#ff8105`）：用于渐变色块系统的纯橙——比 Mistral Orange 更暖、更少红感。

### 次要色与强调色
- **Sunshine 900**（`#ff8a00`）：深金琥珀——阳光色系中最深的一档，用于强强调。
- **Sunshine 700**（`#ffa110`）：暖琥珀金——阳光强调的核心，用于背景与交互元素。
- **Sunshine 500**（`#ffb83e`）：中等金色——平衡的暖感，用于中层强调。
- **Sunshine 300**（`#ffd06a`）：浅金色——用于微妙暖 tint 与次级背景。
- **Block Gold**（`#ffe295`）：淡金——柔和背景点缀与轻微暖意。
- **Bright Yellow**（`#ffd900`）：渐变中最亮的一档——用在色块身份的「顶端」。

### 表面与背景
- **Warm Ivory**（`#fffaeb`）：最浅的页面背景——仅带一丝暖 tint，作为基底画布。
- **Cream**（`#fff0c2`）：主暖色表面与次要按钮背景——明显偏金。
- **Pure White**（`#ffffff`）：用于最大对比元素与浮层表面。
- **Mistral Black**（`#1f1f1f`）：按钮、正文与暗色区块的主深色表面。
- **Accent Orange**（定义为 `hsl(17, 96%, 52%)`）：交互态的功能性强调色。

### 中性色与文字
- **Mistral Black**（`#1f1f1f`）：主文字色与深色按钮背景——接近黑但比纯 #000 更暖。
- **Black Tint**（定义为 `hsl(0, 0%, 24%)`）：浅底上的次级文字用中深灰。
- **Pure White**（`#ffffff`）：深色表面上的文字与 CTA 标签。

### 语义与点缀
- **Input Border**（定义为 `hsl(240, 5.9%, 90%)`）：表单边框用的偏冷浅灰——系统中少数冷色之一。
- **White Overlay**（`oklab(1, 0, 0 / 0.088–0.1)`）：半透明白，用于磨砂玻璃与按钮叠层。

### 渐变体系
- **Mistral Block Gradient**：标志性身份——多段渐变：黄（`#ffd900`）→ 金（`#ffe295`）→ 琥珀（`#ffa110`）→ 橙（`#ff8105`）→ Flame（`#fb6424`）→ Mistral Orange（`#fa520f`）。出现在 Logo 色块、区块背景与装饰元素中。
- **Golden Landscape Wash**：摄影与背景使用暖琥珀叠层，使整页保持统一的金色温。
- **Warm Shadow Cascade**：多层金色阴影，用带琥珀调的透明度堆叠纵深，而非灰色。

## 3. 排版规则

### 字体家族
- **主字体**：很可能为自定义字体（检测到 Font Source），`Arial` 作为回退，扩展栈：`ui-sans-serif, system-ui, Apple Color Emoji, Segoe UI Emoji, Segoe UI Symbol, Noto Color Emoji`

### 层级

| 角色              | 字体           | 字号           | 字重 | 行高               | 字距     | 说明                     |
| ----------------- | -------------- | -------------- | ---- | ------------------ | -------- | ------------------------ |
| Display / Hero    | Arial (自定义) | 82px (5.13rem) | 400  | 1.00（紧）         | -2.05px  | 最大冲击，广告牌尺度     |
| Section Heading   | Arial (自定义) | 56px (3.5rem)  | 400  | 0.95（极紧）       | normal   | 功能区块锚点             |
| Sub-heading Large | Arial (自定义) | 48px (3rem)    | 400  | 0.95（极紧）       | normal   | 次级区块标题             |
| Sub-heading       | Arial (自定义) | 32px (2rem)    | 400  | 1.15（紧）         | normal   | 卡片标题、功能名称       |
| Card Title        | Arial (自定义) | 30px (1.88rem) | 400  | 1.20（紧）         | normal   | 中层标题                 |
| Feature Title     | Arial (自定义) | 24px (1.5rem)  | 400  | 1.33               | normal   | 小标题                   |
| Body / Button     | Arial (自定义) | 16px (1rem)    | 400  | 1.50               | normal   | 正文、按钮文字           |
| Button Uppercase  | Arial (自定义) | 16px (1rem)    | 400  | 1.50               | normal   | 大写 CTA 标签            |
| Caption / Link    | Arial (自定义) | 14px (0.88rem) | 400  | 1.43               | normal   | 元数据、次级链接         |

### 原则
- **单一字重、最大冲击**：全系统使用 400（常规）——即便在 82px 也是如此。仅靠尺寸即可建立权威感，无需加粗，效果反而出人意料地优雅。
- **大字号下的极紧行高**：展示尺寸下行高 0.95–1.00，使上行字的降部几乎贴到下行字的升部——形成密集的招贴式构图。
- **展示层的激进字距**：82px 时 -2.05px 的字距把主视觉文字压成一块整体。
- **大写作为强调**：在按钮标签与区块标记上策略性使用 `text-transform: uppercase`，带有正式的欧式导视气质。
- **无字重变化**：与多数使用 300–700 梯度的系统不同，Mistral 全程 400。层级只靠字号与颜色，从不靠字重。

## 4. 组件样式

### 按钮

**奶油表面（Cream Surface）**
- 背景：Cream（`#fff0c2`）
- 文字：Mistral Black（`#1f1f1f`）
- 无明显边框
- 温暖、友好的次级 CTA

**深色实心（Dark Solid）**
- 背景：Mistral Black（`#1f1f1f`）
- 文字：Pure White（`#ffffff`）
- 内边距：四边 12px
- 无明显边框
- 主操作按钮——深色压在暖底上

**幽灵 / 透明（Ghost / Transparent）**
- 背景：透明 + 轻微深色叠层（`oklab(0, 0, 0 / 0.1)`）
- 文字：Mistral Black（`#1f1f1f`）
- 不透明度：0.4
- 用于次级/弱强调操作

**文字 / 下划线（Text / Underline）**
- 背景：透明
- 文字：Mistral Black（`#1f1f1f`）
- 内边距：8px 0px 0px（仅顶部）
- 极简——以文字链接充当按钮
- 用于第三级导航操作

### 卡片与容器
- 背景：Warm Ivory（`#fffaeb`）、Cream（`#fff0c2`）或 Pure White
- 边框：极少或没有——靠背景色区分容器
- 圆角：接近零——锐利、建筑感转角
- 阴影：暖金色多层（`rgba(127, 99, 21, 0.12) -8px 16px 39px, rgba(127, 99, 21, 0.1) -33px 64px 72px, rgba(127, 99, 21, 0.06) -73px 144px 97px, ...`）——戏剧性的层叠暖阴影
- 特点：金色阴影营造「黄金时刻」光照感

#### 卡片内图片展示
截图中「AI deployments designed for privacy」区块展示了一套典型的**图片卡片矩阵**布局，体现以下规范：

**卡片容器**
- 背景：Pure White（`#ffffff`）——与页面 Warm Ivory 底色形成轻微对比，使卡片「浮出」
- 阴影：沿用品牌暖金色多层阴影体系，使卡片在奶油色页面背景上呈现「浸在午后金光中」的漂浮感
- 圆角：接近零——保持整体建筑感几何语言，不使用圆角卡片
- 内边距：宽裕留白（约 24–40px），四边一致；**卡片外框随图像内容自适应**——不设与素材无关的固定宽高，由「图像在版面中的实际渲染尺寸 + 内边距」共同决定卡片大小，图像变大则卡片同步扩大，仅保证留白规则不变
- 图像在卡片内水平、垂直居中；若单张图在响应式下需限宽，可对图像设 `max-width: 100%` 等约束，**内边距仍按规范保留**，卡片仍随（约束后的）图像包络

**图像内容**
- 卡片内图像以**全彩原版**展示，不做去色或暖调滤镜处理——以图像原有色彩与暖底形成鲜明视觉对比
- 图像按素材比例与场景需求决定显示尺寸，居中对齐；卡片随其包络，靠统一内边距维持稳定节奏与视觉重心
- 适用于多种图像类型，包括但不限于：
  - 合作伙伴 / 第三方品牌 Logo（如 SAP、IBM、Google Cloud、AWS、Azure）
  - Mistral 自有产品图标（带品牌色块渐变，与页面身份一致）
  - 产品截图、功能示意图、插画等说明性图像
  - 风景/摄影类图像（保持原有暖调构图，不额外叠加滤镜）
- 图像本身不承担边框或阴影——装饰层完全由卡片容器的暖金阴影体系负责

**布局行为**
- 卡片组以**不规则散点/错位排列**方式分布于版面两侧，形成围绕中心文字的动态构图——非严格栅格对齐，而是带有设计感的自由浮动
- 左侧卡片与右侧卡片在垂直方向错落，营造空间层次与视觉张力
- 中心区域留给主文字（标题 + 副文字 + CTA），形成内容焦点明确的「卡片环绕文字」结构

**间距与尺度**
- 卡片与卡片之间：约 16–24px，整体不贴合——强调独立浮起感
- 参考截图中的大/小卡观感（如主要伙伴块约 160×120px–200×160px、次要块约 120×80px–140×100px）仅作**视觉密度参考**；实现上以「图像尺寸 + 内边距」自适应为准，不必为卡片写死与图无关的固定像素框

### 输入与表单
- 边框：`hsl(240, 5.9%, 90%)`——系统中唯一的偏冷元素
- 聚焦：强调色描边环
- 极简样式，与稀疏美学一致

### 导航
- 透明导航叠在暖色主视觉之上
- Logo：Mistral「M」字标
- 链接：深色文字（暗色区块上用白色）
- CTA：深色实心按钮或奶油表面按钮
- 极简、宽疏布局


### 特色组件

**Mistral 色块身份**
- 一排色块构成渐变：黄 → 琥珀 → 橙 → 焦橙
- 每一块依次更偏橙/红
- 品牌的视觉 DNA——任何尺寸都可识别

**金色阴影卡片**
- 卡片由暖琥珀多层阴影托起
- 从 16px 到 400px 偏移共 5 层阴影
- 营造 Mistral 独有的「浮在金光里」效果

**深色页脚渐变**
- 页脚通过强烈渐变从暖琥珀过渡到深色
- 页面收尾处有「日落」感

## 5. 布局原则

### 间距体系
- 基准单位：8px
- 刻度：2px, 4px, 8px, 10px, 12px, 16px, 20px, 24px, 32px, 40px, 48px, 64px, 80px, 98px, 100px
- 按钮内边距：12px，或 8px 0px（紧凑）
- 区块垂直间距：非常宽裕（80px–100px）

### 栅格与容器
- 最大容器宽度：约 1280px，居中
- 主视觉：全宽，超大字号叠在暖色背景上
- 功能区块：宽版式 + 强视觉图像
- 卡片栅格：2–3 列

### 留白理念
- **大胆宣言**：巨大标题配合宽裕留白，形成广告牌式冲击——每条陈述都有呼吸空间。
- **暖色虚空**：留白本身也偏暖，因为背景是象牙/奶油 tint，而非纯白。
- **摄影即留白**：大风景图同时承担内容与装饰性留白。

### 圆角刻度
- 接近零：主导半径——多数元素为锐利、建筑感转角
- 这种极致锐利与色彩的温暖形成张力：软色与硬几何并存。

## 6. 纵深与抬升

| 层级                    | 处理                                                         | 用途                               |
| ----------------------- | ------------------------------------------------------------ | ---------------------------------- |
| 平面（Level 0）         | 无阴影                                                       | 页面背景、文字块                   |
| 金色浮起（Level 1）     | 多层暖阴影（5 层，不透明度 12%→0%，琥珀 tint）               | 功能卡片、产品展示、抬升内容       |

**阴影理念**：Mistral 使用单一但极其复杂的阴影——**五层层叠**的琥珀 tint 阴影（`rgba(127, 99, 21, ...)`），从近处 16px 偏移一直延伸到远处 400px 偏移。结果是丰富、温暖的「黄金时刻」光照感，使抬升元素仿佛浸在午后阳光里。这是主流 AI 品牌中最有辨识度的阴影体系之一。

## 7. 宜与忌

### 宜
- 仅使用暖色谱：象牙、奶油、琥珀、金、橙
- 主视觉展示字保持 82px+，字距 -2.05px
- 在品牌时刻使用 Mistral 色块渐变（黄 → 琥珀 → 橙）
- 对抬升元素使用暖金色阴影（琥珀 tint 的 rgba）
- 文字使用 Mistral Black（#1f1f1f）——勿用纯 #000000
- 全篇字重保持 400——让字号与颜色承担层级
- 保持锐利、建筑感转角——圆角接近零
- 在按钮标签与区块标记上使用大写，体现欧式正式感
- 使用带金色校色的暖调风景摄影

### 忌
- 不要引入冷色（蓝、绿、紫）——色板仅限暖色
- 不要使用粗体（700+）——只有 400
- 不要大圆角——锐利几何是有意为之
- 不要使用冷调阴影——阴影必须带琥珀暖感
- 不要用纯白作页面背景——至少暖 tint（#fffaeb）
- 桌面端不要把主视觉文字缩到 48px 以下——广告牌尺度是核心
- 不要使用超过 2 种字重——用字号变化替代字重变化
- 不要在暖色谱之外加渐变——不要蓝到紫、不要冷色过渡
- 不要用通用灰做文字——即便中性色也应偏暖

## 8. 响应式行为

### 断点
| 名称          | 宽度        | 主要变化                                                     |
| ------------- | ----------- | ------------------------------------------------------------ |
| Mobile        | <640px      | 单列、全部堆叠，主视觉文字约缩至 32px                        |
| Tablet        | 640–768px   | 小幅布局调整                                                 |
| Small Desktop | 768–1024px  | 开始出现两列布局                                             |
| Desktop       | 1024–1280px | 完整布局，排版尺度最大                                       |

### 触控目标
- 按钮使用宽裕内边距（至少 12px）
- 导航元素间距充足
- 卡片本身作为大触控区域

### 折叠策略
- **导航**：移动端收折为汉堡菜单
- **主视觉文字**：82px → 56px → 48px → 32px 逐级缩放
- **功能区块**：多列 → 堆叠
- **摄影**：等比缩放，移动端可能裁切
- **色块身份**：等比缩小

### 图像行为
- 风景摄影等比缩放
- 各尺寸保持暖色校色
- 色块渐变元素流体缩放
- 无美术方向突变——各尺寸保持同一暖调构图

## 9. Agent 提示指南

### 快速色值参考
- 品牌橙：「Mistral Orange (#fa520f)」
- 页面背景：「Warm Ivory (#fffaeb)」
- 暖表面：「Cream (#fff0c2)」
- 主文字：「Mistral Black (#1f1f1f)」
- 阳光琥珀：「Sunshine 700 (#ffa110)」
- 亮金：「Bright Yellow (#ffd900)」
- 深色上的文字：「Pure White (#ffffff)」

### 组件提示示例
- 「在 Warm Ivory (#fffaeb) 上做一个主视觉区：82px Arial、字重 400、行高 1.0、字距 -2.05px 的超大标题。文字 Mistral Black (#1f1f1f)。加一个深色实心 CTA（#1f1f1f 背景、白字、12px 内边距、尖角）和一个奶油色次要按钮（#fff0c2 背景）。」
- 「在 Cream (#fff0c2) 上设计一张功能卡片，尖角（无 border-radius）。应用金色阴影体系：第一层 rgba(127, 99, 21, 0.12) -8px 16px 39px。标题 32px 字重 400，正文 16px。」
- 「搭建 Mistral 色块身份：一排从 Bright Yellow (#ffd900) 经 Sunshine 700 (#ffa110) 到 Mistral Orange (#fa520f) 的色块。尖角、无缝隙。」
- 「做一块深色页脚，背景 Mistral Black (#1f1f1f)，文字 Pure White (#ffffff)。页脚链接 14px。顶部用 Sunshine 700 (#ffa110) 的暖渐变过渡到 Mistral Black。」

### 迭代指南
1. 保持暖色温——说「往琥珀偏」而不是「往灰偏」
2. 用尺寸做层级——82px → 56px → 48px → 32px → 24px → 16px
3. 不要加 border-radius——只保留尖角
4. 阴影永远是暖的：「带琥珀调的金色阴影」
5. 字重永远是 400——通过字号与颜色描述强调
